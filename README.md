# Calculadora com Log4j 2

Este é um projeto simples em Java para demonstrar a implementação da biblioteca de logs **Apache Log4j 2** utilizando **Maven**.

## 🚀 Funcionalidades
- Realiza operações simples de soma.
- Registra logs no console com cores (Highlight).
- Salva o histórico de execução automaticamente em um arquivo na pasta `/logs`.

## 🛠️ Tecnologias
- Java 17
- Maven
- Log4j 2.20.0

## 📂 Como rodar
1. Importe como um projeto Maven no Eclipse ou VS Code.
2. Execute a classe `SomaLog.java`.
3. Verifique o console e o arquivo criado em `logs/execucao.log`.
